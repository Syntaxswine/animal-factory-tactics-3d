# Active window animation study

This independent repository is the authoritative workspace for window sneak,
hen fitting/glass timing and pig director belly-swimming animation work.
It replaces the old `animal-factory-window-shatter` working directory.

Run `./start-study.ps1` from PowerShell. The default port is 4460; use
`./start-study.ps1 -Port 4460` to select it explicitly. The launcher resolves
its server from its own location, so the caller's directory does not matter.

Checks: `npm run check` and `npm run build:tactics-3d`.
The 3D remote is `https://github.com/Syntaxswine/animal-factory-tactics-3d.git`.
This study remains on its separate study branch. A backup commit/push does not
approve physical support, merge the experiment into gameplay, or publish Pages.

The original worktree is retained for rollback. Do not edit both locations.
The other `AnimalFactory3D` snapshots remain staging copies until separately
cut over; this switch does not select an authoritative game/editor branch.
